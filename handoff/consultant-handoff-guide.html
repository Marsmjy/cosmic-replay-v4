2. 推荐：Qoder Work 操作步骤

2.1 导入项目

方式 A：Qoder Work 直接打开 GitHub 仓库
https://github.com/Marsmjy/cosmic-replay-v4.git

方式 B：把顾问交付 zip 解压后，在 Qoder Work 中选择 Open Folder

2.2 初始提示词

你是 Cosmic Replay 顾问 Agent。请先阅读：
1. skills/cosmic-replay-overview/SKILL.md
2. skills/cosmic-replay-troubleshooter/SKILL.md
3. skills/cosmic-replay-troubleshooter/references/external-consultant-handoff.md
4. skills/cosmic-replay-troubleshooter/references/pageid-chain-debugging.md
5. skills/cosmic-hr-expert/SKILL.md

目标：协助导入金蝶苍穹 HAR，生成 YAML，用例执行一次通过；若失败，优先排查 pageId 链路，不要硬补 save 字段绕过问题。

2.4 环境信息配置

在 Web UI 右上角齿轮中维护环境，或复制 config/envs/*.example.yaml 后创建本地环境配置。必须配置：

  • base_url：苍穹环境地址
  • username/password：执行账号
  • datacenter_id：数据中心 ID
  • NO_PROXY/no_proxy：确保内网域名不走代理

2.5 OpenAPI / OpenAI-compatible 配置说明

Cosmic Replay 当前主入口是 HAR，不支持直接从 OpenAPI/Swagger 文档生成苍穹回放用例。如果 Qoder Work 需要配置 OpenAI-compatible API key，请在 Qoder Work 的模型设置中配置；Cosmic Replay Web UI 本身不要求 OpenAI key 才能导入和执行 HAR。

3. 其他 AI IDE 接入

AI IDE建议做法注意事项
Codex打开项目目录，按提示加载 skills/，遇到失败直接粘贴“复制 AI 修复指令”。优先使用证据包，不要靠猜。

WorkBuddy以项目文件夹作为 workspace，导入 handoff demo prompt。如果不支持 skill 原生格式，就把 SKILL.md 和 references 作为固定知识库。
Qoder Work推荐入口。导入仓库后让 Agent 按初始提示词读 overview、troubleshooter、HR expert。部署、配置环境、导入 HAR、AI 修复都在同一工作区完成。

4. HAR 使用流程

  1. 浏览器打开金蝶苍穹，F12 → Network，勾选 Preserve log。
  2. 完整录制业务路径：进入菜单 → 新增/维护 → 填字段 → 保存/提交/确认。
  3. 右键 Network → Save All As HAR。
  4. Web UI → 导入 HAR → 上传 HAR。
  5. 在预览页维护智能用例变量和环境相关字段。
  6. 生成 YAML，进入用例详情后再次确认变量面板。
  7. 执行用例或批量执行，查看 PASS/FAIL 与入库证据。
  8. 若失败或入库未验证，点击“复制 AI 修复指令”，交给 AI Agent。

5. 支持范围

已经支持

  • HAR 导入生成 YAML。
  • 智能用例变量识别：名称、编码、描述、手机号、邮箱、日期等。
  • 环境相关字段识别、展示业务编码/名称、可维护覆盖。
  • 在线元数据增强：/metadata/getEntityType.do?entityId=...。
  • cosmic-hr-expert HR 场景知识库辅助字段识别。
  • L0/L1/L2/L3 pageId 链路排查。
  • 批量执行报告、入库状态、人工确认已入库。
  • AI 修复证据包和复制 AI 修复指令。

还不保证 / 需要谨慎

  • 不支持直接从 OpenAPI/Swagger 生成苍穹用例。
  • 新苍穹组件未必一次通过，需要补组件处理器。
  • PASS 不等于入库已验证，保存响应为空要继续排查。
  • 业务校验弹窗可能是录制验证点，不应一律当失败。
  • 不能用删除断言、删除保存步骤、硬补 save 字段来绕过问题。

9. memory 固化自查

以下内容已经固化到 skill 或本手册，不依赖历史对话：

  • pageId 是服务端模型上下文，优先查 pageId 链路。
  • 9 类 HAR 已验证样本是回归基线。
  • 环境字段可维护，手工值优先，不能被旧 auto_resolve 覆盖。
  • pick 字段对用户展示编码/名称，不强迫维护长整数内码。
  • PASS 但入库未验证要进入 AI 诊断或人工确认。
  • AI 修复禁止删除关键步骤和断言绕过问题。
